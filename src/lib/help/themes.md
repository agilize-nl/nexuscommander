# Themes and Icons

Personalize your NexusCommander experience from **Options > Appearance**.

## UI Themes
You can apply pre-installed themes that completely overhaul the window colors, text, separators, and background styling.
- **Dark Themes**: E.g., Midnight, Dracula, Solarized Dark.
- **Light Themes**: E.g., GitHub Light, Solarized Light.

Changes take effect instantly upon clicking **Apply**.

## Icon Packs
In addition to color themes, you can change the vector icons representing files, folders, and archives across the application.
- **Material** (Default): Clean, flat-design icons.
- **Papirus**: Bright, colorful iconography modeled after Linux desktop environments.
- **Lucide**: High contrast, simple outline icons.
