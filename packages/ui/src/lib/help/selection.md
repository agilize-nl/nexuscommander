# Selecting Files

Selecting files is essential for performing batch operations like copying, moving, or deleting.

## Selection Modes
NexusCommander supports two primary selection modes (configurable in **Options > General**):

### 1. Norton Commander (NC) Mode
- **Left-click**: Moves the focus cursor without selecting the file.
- **Right-click**: Selects (marks) or unselects the file.
- **Shift + Arrow Keys**: Quickly select contiguous files.
- **Space**: Toggles the selection of the current file and moves the cursor down.

### 2. Windows Mode
- **Left-click**: Selects the file.
- **Ctrl + Left-click**: Toggles the selection of multiple files.
- **Shift + Left-click**: Selects a range between the last clicked file and the current one.
- **Right-click**: Opens the context menu.

## Advanced Selection
- **Select All**: `Ctrl + Num +`
- **Unselect All**: `Ctrl + Num -`
- **Invert Selection**: `Num *`
- **Select by Extension**: Available from the Select menu, marks all files with the same extension as the currently focused file.
