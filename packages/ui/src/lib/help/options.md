# Options & Settings

NexusCommander allows you to customize almost every aspect of its behavior via the **Options Configuration** dialog.
- You can find the **Options** menu under the **Configuration** menu item, or by clicking the gear icon in the toolbar.

## Main Setting Categories

### General
1. **Language Interface**: Change the application's locale. Requires a restart.
2. **Selection Style (NC vs Windows Mode)**: Determines how clicks and right-clicks operate on files.
3. **Audio Player**: Configure whether audio files are played using the built-in mini music player or the system default application.

### Appearance
1. **Application Theme**: Changes the entire color palette of NexusCommander (e.g., Midnight, Light, Dracula).
2. **File & Folder Icon Theme**: Changes the icon style used in the file pane.
3. **Typography**: Set specific scalable fonts for different sections of the UI, such as the Menu Bar, File list, or Tabs.

### Interface
Customize the elements displayed on-screen.
- Show/hide the Menu bar (`Ctrl+1` alternative).
- Show/hide the command line area.
- Add folder brackets `[..]` or hide the parent directory row.
- Toggle alternating colors on file rows.
