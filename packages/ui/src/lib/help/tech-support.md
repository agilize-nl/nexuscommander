# Technical Support

If you encounter any issues with NexusCommander, there are several ways to get help.

## Common Issues
- **Folder sizes show 0 bytes**: Use `Alt + Shift + Enter` to calculate folder sizes manually, or check your settings to enable automatic calculation.
- **Permission Denied**: NexusCommander requires appropriate system permissions to access certain folders. Try running with elevated privileges if necessary.
- **Missing Icons**: Ensure your Icon Theme is correctly set in **Options > Appearance**.
- **A file does not open in a remote LXC deployment**: In a headless server environment, NexusCommander should prefer its built-in editor or preview modal. If an office document cannot preview, check whether LibreOffice headless is installed on the server.

## Reporting Bugs
If you find a bug, please report it on our **GitHub Issues** page. Be sure to include:
- Your Operating System version.
- NexusCommander version (found in **Help > About**).
- Steps to reproduce the problem.
- Any error messages you saw.
