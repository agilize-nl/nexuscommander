# Creating Folders

Creating a new directory is simple and fast.

## Using the Keyboard
1. Navigate to the desired folder.
2. Press **F7**.
3. A dialog will prompt you to enter the name of the new folder.
4. Press Enter.

## Advanced Usage
- In the creation dialog, you can add forward slashes `/` (or backslashes `\` on Windows) to create nested directories automatically. 
- E.g., `Documents/Work/Archive` will create all three if they don't already exist.
