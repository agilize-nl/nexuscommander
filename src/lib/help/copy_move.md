# Copy and Move

Copying and moving files between the two panels is the core strength of dual-pane managers.

## Basic Workflow
1. **Source**: In the active panel, select the files and folders you want to copy or move.
2. **Destination**: Ensure the opposite panel is open to the desired destination folder.
3. **Execute**:
   - Press **F5** to Copy.
   - Press **F6** to Move.
4. **Confirm**: A dialog will appear asking you to confirm the operation and the destination pathway.

## Drag and Drop
You can also drag selected files from one panel and drop them into the other. 
- A standard drag attempts to **Move** the files.
- Holding `Ctrl` while dragging forces a **Copy** operation.

## Background Operations
Large file transfers are placed in a **Background Task Queue**, allowing you to continue using NexusCommander while the files copy or move. You can view the progress from the Task Manager dialog.
